## 🌟 Why It Beats 9router

1. **4-Level 1000x TokenSaver Pipeline**:
   - **Level 1**: Lossless elimination of conversational filler (`"Sure! I'd be happy to"`, `"As an AI language model"`).
   - **Level 2**: System prompt deduplication across multi-turn CLI agent runs.
   - **Level 3**: Code block and AST whitespace compaction.
   - **Level 4**: Aggressive telegraphic grammar synthesis (saves 50%–75% token quotas).
2. **Unified Multi-Provider Routing**:
   - Routes seamlessly to **OpenAI**, **Anthropic (Claude)**, **Groq**, **DeepSeek**, and local **Ollama** via one standard OpenAI-compatible `/v1/chat/completions` endpoint.
   - Specify provider via header (`x-provider: groq`) or let the model name route automatically.
3. **Cyberpunk Analytics Dashboard (`http://localhost:7700`)**:
   - Live telemetry on requests routed, tokens saved, bytes slashed, and average quota reduction.
   - Built-in interactive prompt compaction sandbox.
   - Real-time live feed of active requests.

## 🚀 Quick Start
```bash
# Launch server and open dashboard:
START_ROUTER.bat

# Or run via Node:
node server.js
```

### Route Your CLI Tools / Apps:
Simply set the base URL to Vortex Router:
```bash
OPENAI_BASE_URL="http://localhost:7700/v1"
```
